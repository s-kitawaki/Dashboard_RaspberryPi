# おへや化の実装計画

ダッシュボードをたまごっち風のドット絵にする改修の計画です。基準は `main`、対象は `rp_weather/frontend` のみで、Worker と Terraform は変更しません。モックアップは [おへや 5つの時間](https://claude.ai/artifact/VTnAwNNeapHuNYwGQ2g2E6) を参照してください（作成日 2026-09-23）。

## 1. フォントを DotGothic16 に統一

- `@fontsource/dotgothic16` を frontend に追加し、`main.ts` で読み込む。Google への通信なしで動く
- `style.css` の font-family を差し替え、主要サイズを 16 の倍数に揃える（時計 96px、気温 64px、為替 60px など）
- パネルは角丸をやめ、3px の実線と角の欠けでドット風の枠にする

## 2. パネル配置の変更

- 「現在の天気」から湿度と更新時刻を外し、その場所に直近3枠の予報（時刻・アイコン・気温）を1行で表示
- 「これからの天気」パネルを削除し、為替レートをその位置に上げる
- 右下はパネルを置かず、背景が見える「おへや」にする
- 左列（時計とカレンダー）は今のまま。時計横のくちぱっちは吹き出しなしで横移動のまま

## 3. 時間帯で切り替わる背景（5種類）

| 時間帯（日本時間） | 部屋 | くちぱっち | おへやのキャラ |
| --- | --- | --- | --- |
| 6:00〜10:59 | あさ・バスルーム | 歩く | 歯みがき（固定） |
| 11:00〜13:59 | ひる・リビング | 歩く | 歩き回る |
| 14:00〜16:59 | 夕方・リビング（夕焼け） | 歩く | 歩き回る |
| 17:00〜20:59 | よる・リビング（星空、電気とテレビ） | 歩く | テレビ前を目的地に含めやすく |
| 21:00〜翌5:59 | よる・寝室 | 眠る | 眠る（固定） |

- 新規コンポーネントが 256×150 の Canvas に描き、`image-rendering: pixelated` で4倍表示。画像ファイルは持たない
- 時間帯ごとにパネルの色も切り替える（昼は明るい紙色、夜は半透明の紺）
- 切り替え時は1秒のクロスフェード。「視差効果を減らす」設定では即時切り替え
- くちぱっちの睡眠開始を 22:00 から 21:00 に変更
- 切り替え時刻は 6・11・14・17・21 時の5回

## 4. おへやのキャラクターの仕組み

- 床の帯を x と y の範囲として背景側が公開し、キャラはその中をランダムな目的地へ上下左右に歩く。着いたら少し止まって次へ
- 手前ほど少し大きく描き、重なり順も y で決める。向きは左右の2方向のみ（正面・背面の絵は描かない）
- 家具の位置は通れない範囲として除外
- あさと寝室は位置固定の1枚絵（歯みがき、睡眠）
- キャラクター本体の追加は今回に含めない。仕組みだけ作り、仮のキャラ1体で動作確認する

## 5. テストとドキュメント

- Playwright の湿度・更新時刻の検証を外し、5時間帯の表示を固定時刻で1件ずつ追加。睡眠判定の 21:00 変更もテスト
- Storybook のストーリーを新配置に更新し、5時間帯を切り替えて見られるようにする
- README の画面説明を更新

## 今回やらないこと

- キャラクターの新規デザイン（仕組みの完成後に別作業）
- 天気に連動した窓の外の絵
- `chore/plain-dashboard` ブランチへの反映

## 経緯

- 2026-09-23 モックアップを5案作成し、案2「時間で変わる部屋」を採用。予報4枠は窮屈だったため3枠に、時計横のくちぱっちは吹き出しなしに変更。時間帯は当初の4区分から「よる・リビング」を足した5区分に変更
